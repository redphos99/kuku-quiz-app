# くくれんしゅう（掛け算九九練習アプリ）

React + TypeScript（Vite）製。データはブラウザの localStorage にのみ保存されます（サーバー不要）。

## コマンド

| コマンド | 内容 |
|---|---|
| `npm install` | 依存パッケージのインストール |
| `npm run dev` | 開発サーバー起動（http://localhost:5173） |
| `npm run build` | 型チェック＋本番ビルド（`dist/` に静的ファイルを出力） |
| `npm run preview` | ビルド結果の確認（Service Worker はこちらで有効） |
| `npm test` | 出題ロジックなどのユニットテスト |

`dist/` の中身をそのまま静的ホスティングに置けば公開できます（相対パスでビルドしているので、サブパスでも動作）。
PWA（ホーム画面追加・オフライン起動）は HTTPS または localhost で配信したときに有効です。

## 仕様メモ（要件定義書で「実装時に決定」としていた点）

- **出題の選び方**: 選んだ段の全問題（段 × 1〜9）から重複なしで出題数ぶんを選ぶ。出題数が全問題数を超える場合は、全問題を一巡してからもう一巡する。
- **出題順**: 「昇順／降順」は段の順。各段の中は 1→9（九九を唱える順）で固定。「ランダム」は完全シャッフル（同じ問題の連続は避ける）。
- **所要時間**: 最初の問題を表示してから最後の問題に回答するまでの実時間（不正解時の解説を読む時間も含む）。
- **正誤表示**: 正解は約0.9秒で自動的に次へ。不正解は正しい答えを表示し、「つぎへ」を押して進む（赤ではなくオレンジで、やさしい言い回し）。
- **記録**: 完了した練習のみ保存（途中でやめた場合は保存しない）。各問題の正誤・回答秒数も `answers` に保存。
- **回答入力**: 画面下のテンキー（片手操作向け）。物理キーボードの数字／Backspace／Enter も使用可。
- **前回の設定**: 出題数・範囲・順序は次回起動時に引き継ぐ。

## 構成

```
src/
  App.tsx              画面遷移
  quiz.ts              出題生成・表示用フォーマット（テスト対象）
  storage.ts           localStorage の読み書き（壊れたデータは無視）
  screens/             設定 / 練習 / 結果 / 記録一覧
  components/Numpad.tsx
public/                manifest・Service Worker・アイコン
```
